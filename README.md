## 🎯 About

Pokémon DevBoard is a futuristic developer dashboard designed to combine a modern developer-focused interface with a fun Pokémon-inspired visual experience.

The project was built to practice **frontend development, responsive UI design, CSS animations, and JavaScript interactions**.

## ✨ Features

* 🎨 Futuristic dark-themed UI
* 📊 Developer dashboard cards
* 📝 Notes section
* 🎮 Pokémon-inspired character section
* ✨ Hover effects and animations
* 📱 Responsive layout
* ⚡ Interactive elements
* 💾 Persistent tasks, notes, theme, and sound preferences with `localStorage`
* 🧭 Working sidebar navigation with smooth scrolling
* 🏆 Achievements and settings panels

## 🛠️ Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling, layout & animations
* **JavaScript** — Interactions and browser storage

## 🚀 Run Locally

```bash
git clone https://github.com/Naveenkumar2028/html-css-pokemon-devboard.git
cd html-css-pokemon-devboard
```

Then open `index.html` in your browser.

Because the project uses only static frontend files, no package installation or backend server is required.

## ⌨️ Interaction Guide

* Add a task with the **Add Quest** button or press **Enter** in the task input.
* Mark tasks complete with the checkbox; task totals update automatically.
* Use the sidebar to jump to dashboard sections with smooth scrolling.
* Open **Achievements** or **Settings** from the sidebar to view the interactive panels.
* Press **Escape** to close an open panel.
* Use the theme and sound buttons to switch preferences; choices are saved in the browser.
* Notes and tasks are stored locally in the current browser and are not uploaded to a server.
